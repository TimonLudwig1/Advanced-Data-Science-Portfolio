# Music Festival Hit Predictor

## Overview

The Music Festival Hit Predictor is an advanced data science project focused on analyzing music industry trends, artist popularity, and festival success patterns using statistical analysis and machine learning techniques.

The goal of this project is to investigate which musical and behavioral factors contribute to an artist's popularity and live-event success. The project combines real-world data collection through APIs, exploratory data analysis, statistical inference, predictive modeling, and interactive visualizations.

This project is part of the larger repository:

`Advanced-Data-Science-Portfolio`

---

# Objectives

The main objectives of this project are:

- Collect real-world music and festival-related data through APIs
- Analyze relationships between audio features and artist popularity
- Apply statistical methods to evaluate hypotheses
- Build machine learning models to predict artist success
- Create visualizations and dashboards for data exploration
- Demonstrate practical applications of data science and statistics

---

# Research Questions

Examples of research questions investigated in this project:

- Which audio features correlate most strongly with popularity?
- Do certain genres perform better at music festivals?
- Can viral artists be predicted using machine learning?
- Are there statistically significant differences between music genres?
- Can popularity trends be forecasted over time?
